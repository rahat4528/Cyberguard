# Security Standards & Compliance

Cyberguard aligns with established security guidelines and standards:
- **OAuth 2.0 Security BCP (RFC 9700)**: Enforcing S256 PKCE, exact redirect URI matching, and token family revocation.
- **OWASP ASVS Level 2**: Targeted verification across authentication, cryptographic storage, and session handling.
- **RFC 6238 & RFC 4226**: Algorithmic conformance for TOTP and HOTP.
- **Zero-Knowledge Architecture**: The server never sees plaintext master passwords, unencrypted credentials, or OTP seeds.
