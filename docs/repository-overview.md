# Cyberguard Repository Overview

Cyberguard is a cybersecurity repository comprising three autonomous, defensively engineered security systems:
1. Authentication System (OAuth) - OpenID Connect and OAuth 2.0 Identity Server.
2. Password Manager - Zero-knowledge credential vault with client-side cryptography.
3. Two-Factor Authentication System - Independent offline authenticator supporting TOTP and HOTP.

Each system is completely isolated: separate processes, isolated data stores, distinct configurations, and dedicated test suites.
