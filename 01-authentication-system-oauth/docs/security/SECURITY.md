# Security Policy

## Honest Claims & Scope Disclaimer
This application is an educational, defensive implementation of an OAuth 2.0 and OpenID Connect identity provider. It has been internally reviewed against OWASP ASVS Level 2 guidelines and the OAuth 2.0 Security BCP (RFC 9700). However, it has not undergone an independent third-party cryptographic and application security audit. It should not be deployed to protect high-value production systems or sensitive personal data without formal third-party verification.

## Vulnerability Reporting
If you discover a security vulnerability, please submit a responsible disclosure report via private issue or contact the repository owner.
